Privacy Policy: Paisa Decoded Autopilot

Last updated: 29 October 2026

Paisa Decoded Autopilot ("the app") is a personal tool. The owner of the Paisa Decoded YouTube channel uses it to manage that channel. It is not offered to the public.

Data the app accesses

  • With the account holder's consent, it uses YouTube API Services to upload videos, set thumbnails and update video privacy or schedule settings, all on the account holder's own channel.
  • It reads aggregate analytics for that channel (views, watch time, average view duration, subscribers gained) to improve future videos.

How data is stored and shared

  • OAuth tokens are stored only as encrypted secrets in the owner's private CI configuration.
  • Analytics summaries are stored in the owner's own repository. No data is sold or shared with third parties.
  • The app does not access data from any other YouTube user.

Google and YouTube

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. You can revoke the app's access at any time at myaccount.google.com/permissions.

Contact

Questions: use the contact details on the channel's About page.
