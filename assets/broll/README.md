Your own B-roll library. It's used before stock footage.

Create one folder per topic word and drop clips inside, for example:

    assets/broll/money/      rupee notes, UPI payments, counting cash
    assets/broll/india/      city skylines, streets, trains
    assets/broll/delivery/   scooters, riders, parcels
    assets/broll/stock/      market screens, charts

When a script line's B-roll query contains the folder name (e.g. "money counting"),
a random unused clip from that folder is used. Clips: mp4/mov, ideally 1080p+, 5–20 s.
CreateStudio animations exported as mp4 work well here.
Keep the total under ~500 MB (GitHub's repo size guidance).
